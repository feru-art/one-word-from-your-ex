One word an ex would use to describe you — the funniest, most painfully honest word takes the whole reward. This entry sends "forgettable": cold indifference that stings harder than anger, because not being remembered at all is worse than being hated. A tiny deterministic Node program writes the word to /output/entry.txt.

## Run it

```sh
node main.ts
```
